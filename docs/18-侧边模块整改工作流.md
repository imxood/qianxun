### 关键设计说明

- **S1 用 `$derived` 而非 `$state` + `$effect`**：背板是 `world` 的纯函数产物，
  `$derived` 天然「关卡变即重建」，且满足 eslint `svelte/prefer-writable-derived`。
  这比原设计意图「手工置 null 触发 $effect」更可靠 —— 后者依赖「一定存在一个
  监听它的 effect」这个极易漏的隐式约定，**正是本次 P0 的成因**。
- **S6 计数而非布尔**：三个消费点（`App.svelte:113`、`SideNav.svelte:93,121`）
  都是真值判断，数字类型天然兼容，无需改调用方。
- **S8 未用 `sendBeacon`**：IPC 是异步的，`beforeunload` 里无法可靠 await；
  改为「组件卸载时 save（IPC 仍可用）+ 关窗时 beforeunload 提示用户」。

### 遗留

- S1/S3/S5/S7 属**接线层**，vitest 无法覆盖（需真机 / 浏览器 / 运行中的 sidecar）。
  建议阶段 3 的 **B1 接线层冒烟测试**优先覆盖这四项。
- S7 的 `pendingAnalyses` 落盘需一次真实队列溢出才能观测；e2e 的 `mario-loop.ts` 可加断言。

## 10. 修复过程中踩到并解决的两个「非计划内」问题

1. **BOM 破坏构建**：用 PowerShell 的 `Set-Content -Encoding UTF8` 改 JSON/Rust 文件会写入 BOM。Tauri 的 JSON 解析器不认 BOM，于是 `cargo build` 直接失败。已全仓扫描并清理。**后续在本仓改文件请优先用 edit 工具，或显式 `-Encoding utf8NoBOM`。**
2. **a11y 规则集不一致**：`svelte-check` 要求 `<nav>` 绑 keydown 时加 `svelte-ignore`，而 eslint 侧插件未启用该规则，会把这条 ignore 判成「多余」。两条规则集不同，只能同时抑制（代码里已注明原因）。
