灰度是关键自检：把所有颜色抽成灰后，五种状态必须仍分得开 （靠轨宽 + 虚实 + 中文词）。分不开就是在靠颜色作弊。

已知取舍：「已完成」的轨用 railIdle，在 canvas 上 只有 1.40:1 —— 这是 05 §2 有意的「完成要退后而不是庆祝」。代价是 灰度下它接近隐形，只剩 1dp 细线 + 「已完成」三个字在撑。 若你认为「已完成」也该一眼可辨，把 --railIdle 调亮即可， 但那就违背了那条设计意图。
