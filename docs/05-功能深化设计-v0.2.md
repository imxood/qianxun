## 1. 终端：从"黑屏"到可靠可用（M4 → v0.2）

### 1.1 设计原则

根因是**一行渲染门**（`tab.id > 0` 吞掉 0 号会话），修复本身极小；本期把终端从"从未跑通"带到"可靠可用"，顺带清理审计发现的成色问题。

### 1.2 修复设计

1. **【P0·根因】渲染门修正**：`{#if tab.id > 0}` → `{#if tab.id >= 0}`（保留负数哨兵过滤意图，不动后端合同）；修复后真机回归：首标签可交互、连开 3 标签、关闭确认、进程退出变灰。
2. **【P1】输出回放（消除 banner 丢失竞态）**：Rust 每会话维护输出环形缓冲（64KB）+ 新增 `terminal_replay(id)`；前端 `listen()` 就绪后拉取回放再进入增量流——提示符必现，不赌监听注册快慢。
3. **spawn 失败可视化**：失败 tab 在 pane 区显示错误条（`Error::Terminal` 中文原因 + 重试按钮），不再只进 console。
4. **关闭确认去 `window.confirm`**：WebView2 下原生 confirm 返回值不可靠，改用项目共用 ConfirmDialog 组件（与笔记域 §2.1-3 同一个）。
5. **kill 显式化**：Session 保留 child 句柄，`terminal_kill` 时 `child.kill()` + wait，保证 exit 事件必达、不残留无视 console close 的 shell。
6. **读泵合批 + 增量 UTF-8 解码**：8–16ms 聚合 emit + `StringDecoder` 式增量解码——`cat 50MB` 性能验收的前置（现每 read 一次 emit，跨块多字节字符会切出替换符）。
7. **规范清理**：7 处 `.lock().unwrap()` → 中毒恢复（规范 §6）；`bg-[#1e1e1]` → `bg-[#1e1e1e]`；TerminalPage 头注释「退出的标签自动移除」与实际行为（只标灰）对齐。
8. **keep-alive 重见触发 fit**：容器从 `invisible` 恢复可见时手动 `fit()` 一次（ResizeObserver 对 visibility 不触发）。
9. **`terminal_list` 处置**：现为半成品（`shell` 恒空串、前端零调用）——本期从合同/Rust/lib.rs 三方同步删除（编码规范"不留半成品"；会话恢复功能不做，YAGNI）。
10. **`cwd` 透传**：`terminal_spawn` 后端已支持，前端开放可选参数——供搜索页「在终端中打开」联动（§3.1 特色点 1）。

### 1.3 体验深化（本期最小集）

- 标签默认标题显示 shell 名（`pwsh`/`powershell`），OSC 序列覆盖；
- Ctrl+Shift+C / Ctrl+Shift+V 接系统剪贴板 + 右键粘贴。

分屏、终端内搜索按 01 文档仍记后续，不在本期。

### 1.4 验收

- 打开终端页 ≤1s 见提示符（含 banner）；键入回显、命令输出正常；首/二/三标签均可用；
- 关闭运行中标签有确认且进程确实退出；`cat` 50MB 不卡 UI、粘贴 1MB 不丢字符（M4 遗留人工项）；
- conpty 回环 `#[ignore]` 测试手跑通过（回归基线）。

## 2. 笔记：修复编辑器与数据契约（M5 → v0.2）

### 2.1 修复设计

1. **编辑器生命周期重构（唯一致命项）**：CodeMirror 封装为独立组件 `NoteEditor.svelte`
   （编码规范 §5：命令式库封装成单一组件），内部 `$effect` 依赖 `host` 挂载/销毁；
   NotesPage 的编辑区容器**常驻渲染**、CSS 类切换显隐（不再用 `{#if}`），预览切换不销毁编辑器；
   `open()` 成功后 `view.dispatch` 换文档 + `view.focus()`（点开即能打字）。
2. **frontmatter 契约闭合（数据破坏级）**：`notes_save` 入参改为结构化 `{vault, path, title, tags, body}`，
   由 **Rust 侧统一拼装 frontmatter**（与解析器同源、单测逐字互逆），前端不再手拼 YAML；
   contract.ts 同步变更（合同比对测试自动锁住）。
3. **新建/确认对话框组件化**：替换 `window.prompt/confirm`（新建、删除确认、AI 面板），为跨平台留路。

### 2.2 体验深化

- **自动保存**：dirty 后 1.5s 防抖 + 失焦即存 + Ctrl+S 手动；「未保存」标记保留；
- **标题/标签结构化编辑 UI**：编辑区顶部行内编辑（用户不再手写 frontmatter）；
- **列表增强**：首行标题、次行摘要（body 首行非标题文本截断）+ 相对时间 + 标签 chips；
- **外部变更感知（轻量）**：窗口重获焦点时 `notes_list` 静默刷新，不做 watcher；
- 可选项（时间允许）：`.trash` 回收站浏览/恢复；`notes_search`（vault 内内存全文过滤，千篇级毫秒）；换库入口。

### 2.3 验收

- 新建 → 输入 → 自动保存 → 重进列表标题/时间正确；预览/编辑来回切可继续输入；
- 首存不丢 frontmatter（回归测试：save 后 read 的 title/tags 一致）；
- 1000 篇笔记列表流畅（Rust walk 实测毫秒级，前端虚拟化按需）。

## 3. 搜索重构：开发者工作区的 Everything（M2 → v0.2）

### 3.0 定位（先立边界）

fff 引擎是**单根工作区索引**（内置忽略 node_modules 等，无内容索引、无 MFT 级全盘能力）。
本期不做全盘秒搜，把定位做成「**开发者工作区的 Everything**」：秒开工作区、毫秒文件名搜索、
流式实时内容搜索、专业级结果操作；能力边界在 UI 上显式表达（空态/提示语），不再"像凑功能"。

### 3.1 文件搜索页 → Everything 式结果表

- **根选择器（RootBar 重构，两页共用）**：盘符胶囊行（新增 `search_list_drives` 枚举逻辑盘：名称/类型/容量）
  - 「浏览…」（dialog 已装配）+ 历史卡片（带"已索引 N 文件"元信息）+ 支持拖拽文件夹进窗；一期维持单根；
- **结果表格**：四列 = 图标+文件名（字节偏移高亮）/ 目录 / 大小 / 修改时间（后两列由 Rust 对返回页 stat 补字段）；
  **表头点击排序**（名称/修改时间/大小，当前页前端排序起步）；固定行高**虚拟滚动**；
- **右键菜单组件**（自绘，跨两页共用）：打开 / 打开所在位置 / 复制路径（**绝对·带引号·POSIX 三形态子菜单**）/
  复制文件名 / **在终端中打开**（terminal_spawn 透传 cwd，见 §1.2-10）；
- **多选与键盘流**：Ctrl/Shift 多选 + 批量复制路径；↑↓ 导航、Enter 打开、Ctrl+Enter 定位、
  Ctrl+Shift+C 复制路径、Esc 清空；
- **浏览模式**：放开空查询短路（commands.rs:171-177），选中根即列出文件（500/页分页），边输边过滤——Everything 的核心交互；
- **类型快筛 chips**：复用 `FileKind`（文件夹/文档/图片/代码…），纯前端过滤已返回结果。

### 3.2 内容搜索页 → 流式实时 grep（差异化主战场）

- **grep 即输入**：接线已有未用的 120ms 防抖（search.svelte.ts:129）；`search_content` 改 **async + Tauri channel
  流式回传命中**（3s 预算内分片推送），配合既有取消令牌接力实现"新输入自动掐掉上一轮"；
- **命中行可操作**：点击命中行 = 打开文件（现 `openFile` 未导入、命中行点不开，必修）；组头/命中行右键复用 §3.1 菜单，
  另加「复制路径:行号」「限定此目录再搜」（设置根为该目录）；
- **过滤器与匹配控制**：扩展名 chips + 自定义 glob（Rust 封装层读文件前过滤）；大小写三态（智能/敏感/忽略）；
  **整词开关**（前端把查询转义后包 `\b…\b` 走 regex 模式实现，零引擎成本）；
- **限额透明化**：2MB 大文件上限、单文件 100 条、时间预算从硬编码改为 **UI 高级选项**（GrepSearchOptions 本就按查询传参）；
  结果工具栏显示已搜文件数/耗时；`aborted` 区分「手动取消」与「被新搜索取代」（令牌加代号）。

### 3.3 Rust 能力新增（合同双登记，优先级序）

1. `search_content` 改 async 流式 + 取消语义修正（**第一优先，同时修复主线程冻结**）；
2. `FileHit` 补 size/mtime；3. `search_list_drives`；4. grep glob 过滤；5. 索引/grep 进度事件（emit）。
   二期再议：多根并存、忽略规则可配置、文件系统变更推送。

### 3.4 前端工程项（随重构一并做）

- 虚拟列表组件两页统一；高亮切片 memo 化（移出 Svelte 模板，现每行每次重渲染重算 byte→char Map）；
- `runFiles` 加请求序号防竞态 + 用已有 `generation` 字段丢弃过期结果；grep 累积结果设上限，超限提示缩小范围；
- 复制路径分隔符形态统一（现 `\` 与 `/` 两套并存）。

### 3.5 验收

- 选盘符/工作区 → 输入即出结果（10 万文件索引后首屏 < 200ms）；空查询可浏览全列表；
- 排序、右键三形态复制路径、打开所在位置、在终端中打开全部可用；多选批量复制可用；
- 内容搜索即输即出命中（流式），命中行可打开；取消立即生效（主线程不再冻结）；
- grep 长任务期间换根不卡（读锁竞态消除）。

## 4. 截屏交互：删"选择"按钮，框完即可拖（M3 → v0.2）

### 4.1 交互模型（纯前端，OverlayPage.svelte 单文件）

`idle / selecting / selected` 三态不变；`tool` 退化为"绘图工具选择器"（`'none'` = 默认空态，**不再是按钮**）。
`selected` 态 `onMouseDown` 改为统一优先级分发器：

1. 文字草稿存在 → 提交；
2. 选区 8 手柄命中 → resize（**任何工具态**）；
3. 【新增】`hitSelectionEdge`：距选区边 ≤5dpr 的带状命中 → 对应向 resize（**任何工具态**）；
4. 无工具态：已选标注手柄 → 缩放；标注命中 → 选中并拖动；框内空白 → **拖动即移动选区**；
5. 绘图工具态：框内按下 = 绘制；文字工具：框内单击 = 落输入框（在 2/3 之后判定）；
6. 选区外按下（任何工具）→ 清标注重开选区。

`onMouseMove/onMouseUp` 由 `drag.kind` 驱动，无需改动。

### 4.2 光标与冲突裁决

- 光标优先级：边线/手柄 > 悬停标注 `'move'` > 区域默认（无工具框内 `'move'`、工具框内 `'crosshair'`、text 工具 `'text'`）；去 `updateCursor` 的 `tool==='none'` 门；
- 冲突裁决：文字落点 vs 边线 = 边线优先；马赛克拖框期间选区不可移动（边线/手柄除外）；标注手柄 vs 选区边线 = 选区优先（外层几何优先）；**双击复制仅无工具态生效**。

### 4.3 验收

- 框选完成**立即**可拖动移动、拖边调大小，全程无"选择"按钮；
- 任意绘图工具激活时边线/手柄仍可调；六种标注绘制/再编辑/Delete 删除/撤销重做不回归。

## 5. 远程闭环：修生效链路 + 升格一级入口（R1 → v0.2）

### 5.1 核心 bug：`sync()` 配置指纹

`GatewayHandle` 增加启动快照指纹（`enabled + bind_ip + port + devices` 的序列化哈希）；
`sync()` 改为：指纹相同且任务存活 → 保留；否则停旧起新。效果：配对/吊销/换网卡/换端口**即时生效**
（网关重建，个人场景瞬断可接受；吊销的"即时全断"语义恰好由此天然满足）。
设备表热更新（RwLock）列为可选优化，本期不做。

### 5.2 UI 升格：设置页卡片 → 一级「远程」页

- SideNav 新增「远程」项（产品三支柱之一，值得一级入口；设置页原卡移除，留指引链接）；
- 页面内容：启用开关、网卡下拉（EasyTier ⚡ 置顶；**空态引导**："未检测到 EasyTier 虚拟网卡——请先安装并启动 EasyTier 组网"，附说明）、端口、状态行（监听地址 + DSH 运行态）、
  「配对新设备」（设备名 + 二维码 + 复制链接）、设备列表（吊销需确认对话框）；
- **自检按钮**：本机带 token 请求 `/qx-gate`，显示「网关工作正常 / 失败原因」——把"能不能用"从猜测变成一眼可见。

### 5.3 测试与真机验收

- axum 内存级集成测试：无 token 401；配对 token → `/qx-gate` 302 + cookie → `/` 200；吊销后 401（同一进程内重建网关验证）；
- 真机（EasyTier 实网 + 手机）：扫码 → 手机完整使用 DSH Web；吊销即时断连；关闭开关后端口无监听。

## 6. Android：SDK 安装与首个 APK（R2 → v0.2）

### 6.1 工具链安装（`D:\programs` 布局，全程免 Android Studio）

1. JDK 21（Temurin）→ `D:\programs\java\jdk-21`，设 `JAVA_HOME`（Capacitor 7/AGP 8.x 要求 21）；
2. Android commandline-tools → `D:\programs\android\sdk\cmdline-tools\latest`，设 `ANDROID_HOME`，
   `sdkmanager` 安装 `platform-tools`、`platforms;android-35`、`build-tools;35.0.0`，接受 licenses；
3. PATH 追加 `...\sdk\platform-tools`（adb）。

### 6.2 壳工程落地

1. `cd mobile && pnpm install`（Capacitor 7 三件套）→ `pnpm add:android` 生成 `mobile/android/`（入库）；
2. `network_security_config.xml` + Manifest 注入**脚本化**（替代 README 手工步骤，`pnpm` 脚本一键完成）；
3. `gradlew assembleDebug` 出 debug APK → `adb install` 真机（无 USB 时无线 adb 或用户协助）。

### 6.3 验收（前置依赖 §5 完成，否则配对 401）

手机加入同一 EasyTier 网 → 壳内粘贴/扫码配对链接 → 直达 DSH Web 可正常对话；
「忘记地址」可重配；壳仅做入口，不带业务逻辑（既定非目标）。
