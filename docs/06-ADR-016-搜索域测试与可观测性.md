# ADR-016 · 搜索域测试与可观测性

> 状态：草稿 v1（V0.5.1 验收后落地）
> 创建：2026-09-19
> 关联：docs/04-里程碑与TODO.md §7.4 S11；汇总设计文档 §7

## 背景

汇总设计文档（4 角度审计产出）指出搜索域（FilesPage / GrepPage / DiskScan 三 tab）存在 **22 个严重 / 28 个中等 / 31 个建议** 问题，其中：

- **测试覆盖盲区**：`src/stores/search.svelte.ts` 0 个 vitest；`commands.rs` 搜索域 0 处结构化日志；字段级合同测缺位。
- **可观测性系统性失败**：`grep env_logger|subscriber` 全仓 0 命中；fff-core 内 16 处 `log::*` 全 no-op；`e2e/_fixture.ts:78` 的 `RUST_LOG: 'info'` 是空头支票。

V0.5.1 落地时已实现：

- 51 个 vitest 单测（grep-merge 9 / status-poller 5 / SearchStore 12 / fileIcon 12 / contract 11 / theme 2）
- 9 个 contract 字段级合同测（防 rename_all silent drift）
- env_logger 初始化 + 5 主路径结构化日志
- ARIA live 区域（GrepPage + DiskScan）

本 ADR 记录搜索域的测试与可观测性 **长期承诺**：哪些必须测、哪些必须打点、谁能改、门禁在哪里。

## 决策

### 1. 测试分层

| 层级       | 工具                             | 范围                                                                                   | 责任                |
| ---------- | -------------------------------- | -------------------------------------------------------------------------------------- | ------------------- |
| 纯函数单测 | vitest                           | `grep-merge.ts` / `status-poller.ts` / `format.ts` / `fileIcon.ts` / `disk/treemap.ts` | 文档 §3 §9 必测清单 |
| Store 单测 | vitest + fake IPC                | `stores/search.svelte.ts`（grepSeq / cancel / dispose）                                | 不挂载组件          |
| 组件级单测 | vitest + @testing-library/svelte | 三 tab 公共骨架（SearchResultsList / HitContextMenu）                                  | 选测；非强制        |
| e2e        | Playwright + CDP                 | FilesPage / GrepPage / DiskScan happy path + cancel + error                            | 探针脚本详见 §3     |
| 后端单测   | cargo test                       | `commands.rs` 五态分支（暖/冷/同根/取消/根切换）；`fff-grep` 公共 API                  | CI 必跑             |

### 2. 可观测性分层

| 层级           | 工具                         | 覆盖                                                         | 何时落                        |
| -------------- | ---------------------------- | ------------------------------------------------------------ | ----------------------------- |
| Rust 日志 sink | env_logger                   | stderr（`RUST_LOG=info` 控制）                               | 启动 setup 内 `try_init`      |
| Rust 搜索域    | `log::*` macros              | search_open 五态 + search_content start/done + 游标不动 warn | 关键路径必加                  |
| 前端 IPC       | dev-only console.debug/error | call() 入参 + latency_ms + 错误 message                      | release build 自动 tree-shake |
| 前端 UI        | aria-live=polite             | GrepPage status / DiskScan 进度行 / FilesPage 错误态         | 必加                          |
| e2e fixture    | qianxun.log tail dump        | 排障时辅助                                                   | docs/07 §2 已锁               |

### 3. CDP 探针脚本（AGENTS.md §4 / docs/07 §1 §4 三处都引用但仓库 0 产物）

补齐 3 个样板：

- `e2e/probe-files.ts` — 选根 → 输文件名 → ≥1 命中 → 双击 = opener.openPath
- `e2e/probe-grep.ts` — 流式分片 → 停止按钮 → aborted=true
- `e2e/probe-disk.ts` — 扫描 → stop → 已部分结果

每个文件加 `data-testid` 各 3-5 个。

### 4. 文档同步责任

- 任何 `#[serde(rename_all = "camelCase")]` struct 字段重命名 → 同步更新 `src/lib/ipc/contract.ts` → contract.test.ts 会拦下漂移。
- 任何 `commands.rs` 新增 `#[tauri::command]` 函数 → 必须 `IPC_COMMANDS` 同步 + contract.test.ts 命令名比对会拦下。
- `docs/04` 任何"完成"勾选项 → 必须有对应 e2e 或单测守住。

## 门禁

| 检查              | 命令                                                                             | 失败动作 |
| ----------------- | -------------------------------------------------------------------------------- | -------- |
| 前端 prettier     | `pnpm prettier --check .`                                                        | CI 红    |
| 前端 eslint       | `pnpm eslint .`                                                                  | CI 红    |
| 前端 svelte-check | `pnpm svelte-check`                                                              | CI 红    |
| 前端 vitest       | `pnpm vitest run`                                                                | CI 红    |
| Rust fmt          | `cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check`                | CI 红    |
| Rust clippy       | `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings` | CI 红    |
| Rust test         | `cargo test --manifest-path src-tauri/Cargo.toml --workspace`                    | CI 红    |

新增 `pnpm all:check` = prettier + eslint + svelte-check + vitest；`pnpm rust:check` = fmt + clippy + test。

## 反模式（明确禁止）

- `try { ... } catch { /* 静默吞 */ }` —— 违反 docs/03 §8。linter 暂无规则，靠评审。
- 字段重命名但不改 contract.ts —— contract.test.ts 字段级比对会拦下。
- search.svelte.ts 内新增私有字段不加 vitest 覆盖 —— 任意重构都是盲改。
- "日志已加 RUST_LOG=info" 但应用不消费 logger —— 这次的根因；env_logger try_init 后必须 stderr 有输出。
